实现使用独立微型 TypeScript DOM 探针，不引入 Nuxt/Vue 或额外 UI 框架：宿主不存在 Nuxt 应用，P0 不需要应用级组件系统。测试与构建复用 Bun、TypeScript、happy-dom。P2 定位方案仍优先 Floating UI，P0 不实现生产 Popover，避免提前引入未使用依赖。

主要维护风险是非公开 HTTP 模块和 DOM 锚点漂移；未知/歧义时拒绝操作，输出有限诊断码。当前实现未复制第三方代码；原仓库 Apache-2.0 LICENSE 保持不变。未来复制 MIT 代码时须同时增加版权与 NOTICE。
