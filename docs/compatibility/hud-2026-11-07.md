# HUD 挂载与卡片衔接修复（2026-11-07）

本轮只交付 HUD 布局和挂载修复。常驻注入的事件恢复、健康检查和 overhead 评估另行实施；不将一次性模式作为后续交付目标。

## 已实现

- 原生布局事件不再强制拆除健康挂载，避免移除/插入外围流式项造成输入框往返移动。
- 原生高度、间距变化时直接更新重叠边距，观察器回调中先更新几何；保持原有节点和焦点。
- 观察整个文档但过滤无关消息和插件自身变更，覆盖缓存分支显示、锚点重建和宿主移除 slot 后恢复。存在原生弹层时保留已有安全挂载，不因拆装改变输入框位置。
- 原生输入框在上层。底层卡片没有上边框和上方圆角，背景与侧边向上延伸至原生下方圆角的起点，补齐直接裁切造成的侧边缺口；文字和卡片不接收鼠标事件。
- 同步最新 UI 决策。保留真实数据读取、额度刷新和原生输入控件契约。
