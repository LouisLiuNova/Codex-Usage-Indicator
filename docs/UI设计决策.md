# UI 当前设计决策

本文件记录用户在本聊天中最新明确确认的展示方式；与原方案、历史 P0 截图或旧说明冲突时，以本文件为准。

## 当前方案（2026-11-06）

1. Composer 指示器位于输入框**外侧下方**。用户已通过选项明确排除底部控制栏内，并提供红色轮廓示意图。
2. 该区域为与输入框等宽的圆角矩形信息栏，栏内**只显示文字剩余量**，例如 `5H 剩余 39% | WEEK 剩余 99%`。数字必须来自实际返回的对应窗口，示例不是固定值。
3. Composer 不创建 SVG、圆环、圆环图标或圆环占位；圆环仅用于侧栏。两个入口仍可打开同一个详情卡片，保留键盘及可访问名称。
4. 原生输入区尺寸、模型/权限/发送控件保持其原有行为。信息栏使用外围 sibling 流式区域，目标占用约 32px，间距由宿主布局决定；不得重设编辑器高度或改变输入内容。
5. 侧栏沿用已验证的原生 rail 内宽约束，当前 52px rail 中圆环宽36px；不能为固定40px圆环撑宽原生 rail。
6. 只有 Weekly 时，文字栏、侧栏和详情均完全移除 5H 部分；文字单项居中，不留下占位，不因此报告连接异常。

## 历史方案及状态

最初的输入框下方双圆环已被用户明确替换。随后曾建议在红框所示控制栏内缩小显示，尝试了 Loader 官方 Composer Accessory；当前窗口未取得可用挂载点，临时预览已清理。用户最终改为本文件中的外侧文字栏，因此不再开发控制栏内的回退实现，也不为该方案申请 composer 权限。

旧截图仅作为历史测试证据，不得作为当前目标。当前仍处开发版：文字栏和侧栏组件已实现并做原生短暂预览；正式 Loader 运行时、自动刷新接线、身份切换、重建及完整实机验收尚未完成。
