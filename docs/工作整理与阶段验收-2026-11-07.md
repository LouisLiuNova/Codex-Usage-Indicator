## 验证证据

- 类型检查：bun run check通过。
- 单元测试：bun run test通过，165项、371个断言。
- 构建：bun run build通过，仍为开发产物，没有正式ZIP。
- 工具与文档：两个新增mjs入口的Node语法检查、git diff --check通过；未运行独立文档构建。
- macOS常驻模式：客户端26.1029.61003已实测真实双窗口、双挂载、详情点击与切换、Esc焦点返回、停用清理及重新启用。
- macOS一次性模式：客户端26.1103.31037当前稳定页面补注入后，注入/等待进程退出，31秒请求数1→2且双挂载、单份样式保持；截图可见5H与Weekly。整理时再次只读复查为ready、coverage=both、slots=2、styles=1。
- 隔离实验：注入子进程退出后仍可继续轮询；Page.reload后runtime为null。该失败用于界定范围，未把模拟Provider当作真实额度。
- 本轮未运行远端CI、后端/E2E完整矩阵、性能压力测试或30分钟持续观察；已有运行时计数不替代持续采样记录。

原始截图、状态及有限诊断留在忽略的artifacts目录；对应总结见[macOS记录](compatibility/macos-arm64.md)。
