# Codex 用量指示器（开发版）

版本：`0.1.0-dev.1`。在 Codex Desktop 输入框下方显示剩余额度，在侧栏提供圆环与共享详情卡片。当前为开发验收版，完整平台兼容与正式发布尚未完成。

## 环境与加载

通过已审阅的 Codex Script Loader `0.6.0`（固定提交 `b6ec28c69af12e9667f57d19823fb46d225756e4`）加载本目录，加载工具需要目标平台的原生 Node.js `22+`。源码构建产物为 `dist/plugin`；`dist/probe` 是另一套诊断工具。

本包只包含插件；完整构建和平台加载步骤位于源码仓库的 `docs/使用指南.md`，可从[项目仓库](https://github.com/LouisLiuNova/Codex-Usage-Indicator)查找。加载前正常结束任务并退出客户端，再按平台指南通过 Loader 启动。

## 查看余量

- 输入框外侧下方为静态文字栏，与原生框装饰重叠约 12px，文字右对齐，无悬停、点击或 Tab 入口。
- 侧栏圆环可悬停预览、点击固定详情；两个圆环共用一张卡片。点击外部、关闭按钮或按 Esc 关闭。
- 5H 为 5 小时窗口，WEEK 为每周窗口；仅提供每周额度时，三处均移除完整 5H 项。
- 真实余量为零时，文字和详情显示“已经用尽”，圆环保留 0% 数字。
- 详情显示剩余量、绝对重置时间、更新时间与连接状态，使用系统时区并显示 UTC 偏移。

## 刷新与状态

真实数据通过当前 Renderer 的唯一内部 HTTP 客户端读取固定 `GET /wham/usage`。正常每 30 秒查询；普通查询及回到前台时保留已有数据，成功后替换，减少反复显示“连接中”。

网络失败会保留同账号最近数据并标记连接状态，超过 90 秒标为过期；失败退避，429 遵守 Retry-After。无手动刷新，不从页面文字、其他模型池、凭据文件或 App Server 补数据。

发现原生账号菜单活动时清空并暂停读取，切回窗口后重新确认前台上下文。真实账号切换仍待实机验证，不声明已有稳定的宿主账号通知接口。

## 停用与更新

常驻 Loader 中禁用或卸载会取消请求和定时器，移除两处 UI、详情、样式、观察器、监听器与生命周期全局。热重载由 Loader 先 stop 再 start。更新应先停用旧实例，再通过 Loader 更新构建包并启用；完整升级验收仍待完成。

macOS 一次性模式属于实验：当前稳定页面已有注入器退出后继续取数的短时证据，启动期加载不可靠，完整重载和新窗口恢复未通过。此模式不自动应用注册表变更，可正常退出客户端结束实例；不能将常驻模式的管理与清理结论直接用于一次性模式。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 下方文字不能点击 | 使用侧栏圆环打开详情，下方为静态展示 |
| 只有 WEEK | 正常的受支持窗口情况，不按套餐伪造 5H |
| 没有 UI | 确认包已启用、由 Loader 启动且当前页面有安全挂载位置 |
| 数字未变化 | 查看详情更新时间；余量不变不代表没有刷新 |
| 连接中断或已过期 | 检查网络与客户端登录，等待退避后的重试 |
| macOS 重载后消失 | 一次性模式的已知限制，按平台指南重新加载或补注入 |

## 权限与兼容边界

仅申请 `dom`，不读写浏览器本地存储，不读取或复制凭据，不修改安装包，不控制模型或发送消息。不同 Renderer 各有独立实例，不宣称跨窗口共享请求。本项目不隶属于 OpenAI，内部 HTTP/DOM 依赖可能随客户端版本变化。

Windows x64 已有真实读取、挂载和局部交互证据，Esc 关闭与焦点返回经人工确认。macOS arm64 常驻模式已验证真实读取、双挂载、鼠标详情、Esc、焦点返回及停用恢复；一次性模式只有局部证据。11 月 9 日加载器失败终态修复仍待回归。完整键盘、页面矩阵、当前版本持续使用及 Windows ARM64 实机验证未完成，构建通过不代表正式兼容。
