# 当前状态

更新：2026-11-07。版本：0.1.0-dev.1。当前为开发验收版，完整平台Go与正式v0.1.0发布门槛尚未通过。

## 已实现

- 输入框外侧下方为等宽静态文字栏，重叠12px、文字右对齐，无悬停、点击或Tab入口；详情只通过侧栏圆环打开。原生输入框严格覆盖底层卡片，无底层上边框/上方圆角，按实际下缘圆角补齐侧边。
- 健康挂载保留节点；原生高度和gap变化时直接更新几何，避免拆装造成的输入框往返移动。文档观察过滤无关消息和插件变更，覆盖缓存分支、锚点重建及slot被宿主移除后的恢复。
- 真实新聊天增加home流式适配，透明surface改读实际body圆角；保留原生输入区尺寸和控件契约。
- macOS加载改为常驻CDP连接、主文档预注册、页面事件恢复、15秒健康检查、注册表变更同步与60秒计划兜底。建立/重建连接前核验归属，断线退避重连；健康状态不重复注入或每秒启动进程查询。历史一次性模式已从当前入口移除。
- 停止监督器取消待启动回调、移除预注册并清理Renderer；断线后尝试重新核验并清理，无法确认时不宣称清理成功。
- Renderer唯一内部HTTP客户端、固定GET /wham/usage、严格主池/窗口校验、整份快照替换；不读取凭据，不以App Server补数据。30秒取数、429退避、90秒新鲜度、账号风险清空及迟到响应隔离保持原有契约。
- 修复账号菜单关闭后停留“连接中”：关闭菜单自动重验并恢复轮询，菜单打开期间继续清空并暂停，focus/online不越过保护；诊断区分contextPaused与连接状态。
- 5H/WEEK统一分区：≥30%保留青/紫色，10%≤余量<30%为琥珀色，<10%为红色与告警标记；仅正数<10%提示“即将用尽”，0%继续显示“已经用尽”，未知值不产生低余量标记。
- 真实0显示“已经用尽”，普通查询保留已有数据；Weekly-only完全移除5H，详情显示绝对时间和每30秒刷新说明。
