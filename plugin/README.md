# Codex 用量指示器（开发版）

通过 Codex Script Loader 0.6.0 加载。输入框外侧下方为等宽圆角文字栏，与原生框装饰重叠约12px、文字右对齐；下方文字无悬停、点击或Tab焦点，详情仅通过侧栏圆环打开。只有 Weekly 时三处均移除5H。

真实数据仅通过当前 Renderer 的唯一内部 HTTP 客户端读取固定 GET /wham/usage；每30秒采样，普通查询及回到前台时保留已有数据，成功后直接替换，避免反复显示“连接中”。网络异常保留同账号最近数据并按新鲜度标记，失败退避，429尊重Retry-After。详情显示绝对重置时间和系统时区。无手动刷新，不从页面文字、其他模型池、凭据文件或App Server补数据。

仅申请dom，不读写本地存储，不修改安装包，不控制模型或发送消息。发现原生账号菜单活动时先清空并暂停读取；观察到菜单关闭或切回窗口后，重新发现客户端并读取当前上下文；菜单仍打开时不恢复。此保守行为及账号切换实机验证仍在开发中，尚未声明具有稳定的宿主账号通知接口。

在Loader中禁用或卸载会取消请求和定时器，移除两处UI、详情、样式、观察器、监听器与生命周期全局。热重载由Loader先stop再start。不同Renderer各有独立实例，不宣称跨窗口共享请求。

这是开发候选，完整跨平台发布门槛尚未通过。Windows当前build已完成读取、挂载及局部交互验证，Esc关闭和焦点返回已由用户人工确认；macOS arm64已完成真实读取、双挂载、鼠标详情、Esc与焦点返回、停用恢复验证。其他键盘场景、完整平台矩阵及Windows ARM64仍待实测。不要将源码单测或包构建通过当作正式发布兼容性保证。

macOS当前采用常驻CDP连接、页面事件恢复与15秒健康检查；注册表变更事件同步启停，60秒兜底检查计划。停止监督器会取消预注册并清理Renderer。一次性模式不再作为交付目标，命令、指标含义及实测范围见源码仓库中的 `docs/compatibility/resident-injection.md`。
