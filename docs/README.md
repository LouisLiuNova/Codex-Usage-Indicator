## 文档维护约定

功能或使用步骤变化时同步首页、使用指南和随包说明；验收结论变化时更新当前状态、验收矩阵和对应平台证据。保留历史失败与验证范围，不用旧记录覆盖新结论。

分别记录类型检查、单元测试、构建、文档检查、真实客户端运行和远端状态。没有执行的检查明确标注待验证，不把构建通过当作实机兼容，也不把历史测试作为后续修复的回归结果。
