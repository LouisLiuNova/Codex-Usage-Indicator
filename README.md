# Codex Usage Indicator

在 Codex Desktop 中查看当前主账号的剩余额度：输入框下方显示简洁文字，侧栏圆环提供用量详情。

**当前版本：`0.1.0-dev.1`，开发验收中。** Windows x64 与 macOS Apple Silicon 已有部分实机证据，完整兼容矩阵与正式发布尚未完成。最新进展以[当前状态](docs/当前状态.md)为准。

## 功能与界面

- **随时查看余量**：输入框外侧下方的静态文字栏显示 5H 与 WEEK，文字靠右，不占用 Tab 焦点。
- **按需查看详情**：悬停或点击侧栏圆环，查看剩余比例、重置时间、更新时间和连接状态。
- **自动更新**：正常情况下每 30 秒查询；普通查询保留当前数据，成功后更新。断网时保留同账号最近数据并标记状态。
- **如实显示窗口**：接口只返回每周额度时，仅显示 WEEK；真实余量为零时显示“已经用尽”。

## 快速开始

开发版需要自行构建，并通过固定版本的 Codex Script Loader 加载。准备条件：Bun `1.3.13`、原生 Node.js `22+`、目标平台的 Codex Desktop，以及已审阅的 Loader `0.6.0` 源码（固定提交见[使用指南](docs/使用指南.md#环境准备)）。

在项目根目录执行：

```sh
bun install --frozen-lockfile
bun run check
bun run test
bun run build
```

构建后加载 **`dist/plugin`**。`dist/probe` 是技术诊断探针，两者用途不同。

接下来按[使用指南：加载开发版](docs/使用指南.md#加载开发版)完成平台对应步骤。加载会涉及客户端退出与重新启动，请先结束正在执行的任务。macOS 一次性模式属于实验入口，限制见指南。

## 使用方式

输入框下方只展示余量，详情入口位于侧栏。悬停圆环可预览，点击可固定详情；点击卡片外部、关闭按钮或按 Esc 可关闭。两个圆环共用一张详情卡片。完整键盘操作仍需按平台验收。

详情中的重置时间使用系统时区，附 UTC 偏移；“更新于”表示最近成功取得数据的时间。常见状态及停用方式见[使用指南](docs/使用指南.md)。

## 常见问题

| 问题 | 说明与处理 |
| --- | --- |
| 为什么只有 WEEK？ | 服务端可能只提供每周窗口，这是正常情况；插件不会按套餐推测或补造 5H。 |
| 为什么输入框下方不能点？ | 该位置是静态文字栏，请使用侧栏圆环查看详情。 |
| 为什么没有显示？ | 先确认加载的是 `dist/plugin` 且已启用；设置页、缺少安全位置或结构有歧义时可能不挂载。排查步骤见[使用指南](docs/使用指南.md#常见问题与排查)。 |
| 为什么刷新时仍显示旧数字？ | 普通查询保留已有数据以减少闪动；网络异常与过期状态在详情中提示。 |
| macOS 重载后消失怎么办？ | 一次性加载尚不能自动恢复，已有调试端口时可按指南补注入；没有端口时需重新走加载流程。 |
| 可以当作正式稳定插件使用吗？ | 目前适合开发验证，正式安装、升级及完整平台验收尚未完成。 |

## 权限与数据

插件仅申请 `dom` 权限，通过当前页面的内部 HTTP 客户端读取固定 `GET /wham/usage`，不读取或复制凭据文件，不读写浏览器本地存储。账号标识只用于内存中的归属比较，不展示到 UI。

发现账号菜单活动时会保守清空并暂停读取，返回窗口后重新确认上下文。真实账号切换仍待实测。App Server 仅用于独立诊断，不为插件补数据；插件不控制模型或发送消息。

本项目不隶属于 OpenAI，依赖非公开客户端接口与页面结构。相关维护边界见[参考来源](docs/参考来源.md)。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `bun run check` | TypeScript 类型检查 |
| `bun run test` | 项目单元测试，限定 `tests` 目录 |
| `bun run build` | 构建开发插件、Renderer 探针和独立 App Server 探针 |
| `bun run probe:app-server` | 可选的独立 App Server 诊断，不是启动插件的必要步骤 |

构建产物位于 `dist/`，不进入 Git。源码位于 `plugin/src/`，构建与诊断工具位于 `tools/`。测试通过、构建成功、实机使用和正式发布分别记录，不能互相替代。最新验证基线与未完成项见[当前状态](docs/当前状态.md)。
